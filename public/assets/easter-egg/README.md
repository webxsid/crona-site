# LOTR easter egg asset

`one-ring.png` is a local copy of [AnneauUnique.png on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:AnneauUnique.png), downloaded from the original file endpoint.

The Wikimedia Commons page lists the image as released to the public domain by its uploader. The image is used as a decorative, non-essential easter egg on the Crona website.
