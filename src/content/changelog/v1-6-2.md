Crona v1.6.2 updates the public stable line around three meaningful product changes: Momentum becomes rest-aware, focus sessions become more issue-aware before they start, and the Windows managed-install story moves to Scoop with better runtime reliability behind it.

## Added
- Custom Momentum now respects protected rest and away days instead of treating them as broken streak buckets.
- Momentum detail now exposes protected days, adjusted targets, skipped buckets, and original versus effective targets.
- Issue focus now supports a dedicated no-break `Timer` mode alongside Pomodoro profiles.

## Changed
- Daily Momentum buckets can be skipped when protected time means the day should not count.
- Weekly and monthly context-based Momentum can reduce required time when protected days remove real availability.
- Timer defaults now use the remaining estimate instead of ignoring already logged work.
- Timer and Pomodoro dialogs now show worked-versus-estimate context, total duration, and an `Ends At` preview before the session begins.
- Windows managed installs now use Scoop manifests for stable and beta channels.

## Fixed
- Windows alert testing no longer blocks IPC while notification or sound checks are running.
- Windows named-pipe endpoints are runtime-scoped, which reduces `Access is denied` collisions between overlapping sessions.
