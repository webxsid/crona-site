Crona v1.7.1 is a focused fix for the no-break countdown timer.

## Fixed
- Extending an expired countdown now starts the TUI clock from the added duration.
- Countdown clocks, remaining-time labels, end-time previews, and progress now stay aligned with the timer's current remaining time.
- The TUI refreshes the timer when a local countdown reaches zero, so the commit-or-extend prompt reopens even if an event arrives late.
- Extended countdowns can expire repeatedly and emit the completion flow after every extension.
