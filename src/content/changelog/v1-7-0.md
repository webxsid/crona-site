Crona v1.7.0 improves the day-to-day timer and reminder flow while preparing the local daemon for a future Mac client. The companion work in this release is an integration contract, not a shipped desktop application.

## Added
- A choice of check-in or plan-the-day reminders. Each stops after you complete the corresponding daily action.
- A dedicated countdown timer mode, with duration-only extensions.
- An `Ends At` preview for running timers with a meaningful deadline.
- Better issue status choices that follow the current lifecycle rules.
- Local IPC methods and events for a future native client to receive daemon-owned alerts.

## Changed
- Countdown setup no longer accepts Pomodoro-only break settings.
- Ending a timer now requires a commit-style session summary.
- Countdown completion and extension prompts use countdown-specific language.

## Fixed
- Issue status choices no longer offer invalid transitions or changes while that issue has an active focus session.
- Countdown state now survives restarts and stays correct through expiry and extension.
- The local alert backend continues to deliver alerts if a future native client disconnects or declines a delivery.
